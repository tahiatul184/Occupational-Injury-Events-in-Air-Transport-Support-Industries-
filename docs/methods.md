# Fixed benchmark methods

The scope is NAICS prefix 4881, support activities for air transportation. The target is the first digit of an OIICS Version 2 event or exposure code. Divisions are 1 violence and other injuries by persons or animals; 2 transportation incidents; 3 fires and explosions; 4 falls slips and trips; 5 exposure to harmful substances or environments; 6 contact with objects and equipment; and 7 overexertion and bodily reaction. They describe event mechanisms rather than injury nature or causal hazards. ITA targets are BLS OIICS 2.01 autocoder predictions.

SIR uses Final Narrative. ITA combines incident description, preceding activity, event sequence, injury or illness, and object or substance fields. Case-insensitively repeated values are omitted; whitespace is normalized. Valid UTF-8 is retained; invalid bytes use Windows-1252 with undefined bytes retained as Latin-1 code points. Location text is excluded, although the reference autocoder used six fields.

Conservative groups connect prior source groups, exact normalized-text hashes, and normalized establishment/city/state/date keys. SIR training is 2015–2020, validation 2021, and holdout 2022. Groups reaching the coding transition in 2023 or later and previously inspected development groups are excluded. ITA comparisons use actual 2023 or 2024 incident dates and remain outside model selection. The checksum-frozen cohort preserves all exclusions.

Training-only TF-IDF uses word unigrams and bigrams, `min_df=2`, `max_features=30000`, lowercasing, Unicode accent stripping, sublinear TF, smoothed IDF and L2 normalization. It fits 1,145 features, with no stemming, lemmatization or stop-word removal. Logistic regression uses balanced weights, C=1, L2 regularization, L-BFGS and 2,000 iterations. LinearSVC uses balanced weights, C=1 and 10,000 iterations. The baseline predicts the training majority division, falls. Random seed is 2026. There is no tuning search, cross-validation, synthetic resampling or refit on validation.

Selection uses validation macro F1 over reference-present divisions. Fixed candidate ordering resolves the tie in favor of logistic regression. Both supported and fixed-seven macro F1 are reported with undefined class scores set to zero. Conditional percentile intervals use 500 group resamples, seed 2026, retaining each original cohort's supported divisions.

Reproduction checks cover counts, partition integrity, source-target consistency, metrics, intervals, predictions and confusion counts. Conservative linkage is imperfect; there is no employer-level holdout. Small rare-class support, reporting selection and unverified coding provenance constrain interpretation. Computational reproduction does not establish independent label accuracy, ground-task eligibility, causality, prevention benefit or local validity in Bangladesh. The bibliography associated with the manuscript is provided in `references.bib`.
